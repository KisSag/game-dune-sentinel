# Dune Sentinel

UE 5.7. Version 1.0.1; commit `3edf1e4b8550ec38644f52725f24c65c9f52c846`.

## Requirements

Windows 10/11, a DirectX 12 GPU, Unreal Engine 5.7 and its supported C++ toolchain. Git LFS and Python 3.11+ are required to restore and replay the project.

## Package contents

The delivery includes the brief, design, actual creation records, replay, reference media and integrity manifest.
The full archive additionally contains UEProject/, Build/, History/ and separate task/grader documents.

## Play the game

Run Build/DuneSentinel.exe from the full archive. Enter starts flight; W/S pitch up/down, A/D roll and Q/E yaw. Space accelerates and either Ctrl key brakes. Left mouse fires the cannon and F launches a missile. Tab selects a target; hold right mouse to track it and release to restore the flight view.

## Replay the creation process

The verified replay reproduces this iteration's recorded adoption and organization of existing UE 5.7 assets. These adoption operations are not represented as new native authoring. Follow ReplayScripts/README.md; its verification report records the actual scope and result.

## Restore the git history

The repository itself is the history. The full archive additionally contains an anonymized bundle and its LFS objects.

## Tasks

The full archive provides task.json and grader.json separately under Tasks/<name>/. Only the task document and the start snapshot are supplied to the agent. This repository mirror omits those documents.
